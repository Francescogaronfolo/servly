# Servly

Demo statica di una piattaforma per richieste di servizio e fornitori locali.

## Stato attuale

- Nessun pagamento reale.
- Nessun caricamento immagini.
- Nessun dato sensibile reale.
- Credito, sblocchi e profilo sono salvati solo nel browser con localStorage.

## Flusso demo

1. L'utente cerca per categoria, nome o luogo.
2. Visualizza richieste e fornitori in evidenza.
3. Apre una scheda con dati protetti.
4. Sblocca i dettagli usando credito demo.
5. Ritrova i contatti sbloccati nell'area personale.

## Roadmap

- Firebase Authentication per registrazione utenti.
- Firestore per richieste, fornitori, wallet e contatti sbloccati.
- Stripe Checkout per ricariche credito, solo dopo verifica fiscale e legale.
- Informativa privacy e consenso specifico per comunicazione dati a terzi.
- Sistema feedback finale e Indice Servly.
